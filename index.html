📐 PARTE I: Fundamentos Matemáticos Esenciales

⚠️ Importante: Esta sección es crítica. Cada concepto aquí es requerido para entender RL.

1.1 Probabilidad: Variables Aleatorias y Esperanza

En RL, trabajamos constantemente con incertidumbre. El entorno es estocástico (aleatorio).

Variable Aleatoria

Definición: Una variable aleatoria X es una función que asigna un valor numérico a cada resultado de un experimento aleatorio.

Ejemplo: Lanzar un dado. X puede ser {1, 2, 3, 4, 5, 6}. Cada valor tiene probabilidad P(X=k) = 1/6.

Distribución de Probabilidad

Denotamos la probabilidad como:

P(X=x) = p(x)

La suma de todas las probabilidades es 1 (normalización):

∑x P(X=x) = 1

¿Por qué esto importa en RL? El entorno tiene una dinámica probabilística. Cuando ejecutas una acción a en estado s, el siguiente estado s' es aleatorio con probabilidad P(s'|s,a).

Esperanza (Media Esperada)

E[X] = ∑x x · P(X=x)

Es el "valor promedio" si repites el experimento infinitas veces.

Ejemplo: Dado justo. E[X] = 1(1/6) + 2(1/6) + ... + 6(1/6) = 3.5

Esperanza Condicional

E[X|Y=y] = ∑x x · P(X=x|Y=y)

En RL: La recompensa esperada después de tomar acción a en estado s es:

E[R|S=s, A=a] = ∑r r · P(R=r|S=s, A=a)

1.2 Álgebra Lineal: Vectores y Matrices

Vectores en ℝd

Un vector x ∈ ℝd es una columna de d números reales:

x = (x1, x2, ..., xd)T

Ejemplo en RL: Un estado podría ser s = (posición, velocidad) ∈ ℝ2.

Producto Punto (Dot Product)

x · y = ∑i=1d xi yi

En RL: Si θ es un vector de pesos y x es un estado, entonces θ · x calcula el valor estimado del estado.

Norma Euclidiana

||x|| = √(x · x) = √(∑i=1d xi2)

La norma mide la "magnitud" o "longitud" del vector.

1.3 Cálculo: Derivadas y Gradientes

Derivada Parcial

∂f/∂xi mide cómo cambia f cuando cambias solo la variable xi un poco.

Ejemplo: Si f(x, y) = 3x2 + 2xy + y, entonces:

∂f/∂x = 6x + 2y

∂f/∂y = 2x + 1

Gradiente

∇f(x) = (∂f/∂x1, ∂f/∂x2, ..., ∂f/∂xd)T

El gradiente apunta en la dirección de máximo crecimiento de f.

Interpretación crucial: Si quieres minimizar f (como en ML), debes ir en la dirección opuesta:

xnuevo = x - α∇f(x) (descenso de gradiente)

🎮 PARTE II: Aprendizaje por Refuerzo (Sutton & Barto)

2.1 ¿Qué es Aprendizaje por Refuerzo?

Definición: El aprendizaje por refuerzo es un marco de aprendizaje donde un agente interactúa con un entorno, recibiendo estados y recompensas, con el objetivo de aprender una política que maximice la recompensa acumulada a lo largo del tiempo.

Componentes Clave

  1. Agente: Entidad que aprende y toma decisiones
  2. Entorno: Todo aquello externo al agente con el que interactúa
  3. Estado s ∈ S: Descripción de la situación actual
  4. Acción a ∈ A: Lo que el agente puede hacer
  5. Recompensa r ∈ ℝ: Señal de retroalimentación inmediata
  6. Política π(a|s): Estrategia que mapea estados a acciones

Loop de Interacción

En cada paso de tiempo t:

  1. Agente observa estado St
  2. Agente ejecuta acción At ~ π(·|St)
  3. Entorno devuelve recompensa Rt+1 y nuevo estado St+1

2.2 Diferencias con Aprendizaje Supervisado

Aspecto Supervisado Refuerzo
Datos Etiquetas correctas (x, y) dadas Solo recompensas r (señal débil)
Feedback Inmediato después de cada predicción Retrasado, después de varios pasos
Exploración No necesaria Esencial para aprender
Datos generados por Humanos que etiquetan El agente interactuando

🔄 PARTE II.2: Procesos de Decisión de Markov (MDPs)

3.1 Definición Formal de un MDP

Un MDP está caracterizado por:

M = (S, A, P, R, γ)

Donde:

  • S: conjunto finito de estados
  • A: conjunto finito de acciones
  • P(s'|s,a): probabilidad de transición (dinámica)
  • R(s,a,s'): función de recompensa esperada
  • γ ∈ [0,1]: factor de descuento

3.2 Propiedad de Markov

Propiedad de Markov: El futuro es independiente del pasado dado el presente:

P(St+1 | St, At, St-1, At-1, ...) = P(St+1 | St, At)

El estado St contiene TODA la información necesaria. No necesitas recordar qué pasó hace 10 pasos.

¿Por qué es crítico? Sin la propiedad de Markov, no podrías resolver RL eficientemente. Tendrías que recordar toda la historia, lo cual es computacionalmente prohibitivo.

3.3 Horizonte y Retorno

Retorno (Return)

Gt = Rt+1 + γ Rt+2 + γ2 Rt+3 + ... = ∑k=0∞ γk Rt+k+1

¿Qué representa? La recompensa acumulada futura desde el paso t.

Factor de descuento γ:

  • γ = 0: Solo importa la recompensa inmediata Rt+1
  • γ = 1: Todas las recompensas futuras son igualmente importantes
  • 0 < γ < 1: Balance entre inmediato y futuro (típicamente γ ≈ 0.99)

¿Por qué descuentar?

  1. Recompensas futuras son menos ciertas que inmediatas
  2. Matemáticamente, garantiza que la serie converja
  3. Biológicamente, los agentes prefieren recompensas cercanas

📊 PARTE II.3: Ecuaciones de Bellman

🔑 Crítico: Las ecuaciones de Bellman son el corazón matemático de RL. Cada algoritmo RL las usa.

4.1 Función de Valor de Estado Vπ(s)

Vπ(s) = Eπ[Gt | St = s]

Es el valor esperado de todas las recompensas futuras si:

  • Comienzas en estado s
  • Sigues la política π

4.2 Ecuación de Bellman para Vπ(s)

Ecuación de Bellman para Vπ(s):

Vπ(s) = ∑a π(a|s) ∑s',r P(s',r|s,a)[r + γ Vπ(s')]

Interpretación: El valor de un estado es:

  1. La recompensa inmediata esperada r
  2. Más el valor descontado del siguiente estado γ Vπ(s')

Esto es una relación recursiva: puedes calcular V(s) en términos de V(s').

4.3 Función de Valor de Acción Qπ(s,a)

Qπ(s,a) = Eπ[Gt | St=s, At=a]

Es el valor esperado si ejecutas acción a y luego sigues política π.

4.4 Ecuaciones de Bellman Óptimas

La ecuación de Bellman Óptima (fundamental):

Q*(s,a) = E[r + γ maxa' Q*(s', a')]

Si pudieras calcular Q*(s,a), podrías obtener la política óptima:

π*(s) = argmaxa Q*(s,a)

¿Por qué es revolucionaria? Los algoritmos RL como Q-Learning están diseñados específicamente para estimar Q*(s,a) usando esta ecuación.

🤖 PARTE II.4: Q-Learning

5.1 El Problema: No Conocemos P y R

En la práctica, no conocemos:

  • P(s'|s,a): Dinámica del entorno
  • R(s,a,s'): Función de recompensa verdadera

Solo podemos muestrear experiencias (s, a, r, s') interactuando.

Solución: Q-Learning aprende Q* directamente de experiencias.

5.2 Algoritmo Q-Learning

Actualización Q-Learning:

Q(s,a) ← Q(s,a) + α[r + γ maxa' Q(s',a') - Q(s,a)]

Componentes:

  1. α ∈ (0, 1): Tasa de aprendizaje
  2. r: Recompensa observada
  3. γ maxa' Q(s',a'): Estimación del valor futuro
  4. r + γ maxa' Q(s',a') - Q(s,a): Error TD (Temporal Difference)

5.3 ¿Por Qué Q-Learning es Off-Policy?

Q-Learning es off-policy porque:

  1. Política de comportamiento: Usas una política de exploración (ej: ε-greedy)
  2. Política objetivo: Pero aprendes la política greedy que usa maxa' Q(s',a')
  3. Desacoplamiento: Las acciones que tomas no tienen que ser óptimas; aún así aprendes la política óptima

Ventaja: Puedes explorar activamente mientras aprendes la política óptima.

📝 PROBLEMA 1: Aprendizaje por Refuerzo (2 puntos)

1.1 Objetivo del RL - Selecciona todas las correctas

  1. El objetivo del RL es minimizar la pérdida entre predicciones y etiquetas
  2. El objetivo del RL es aprender una buena política con supervisión nula o limitada
  3. Para que un algoritmo de RL funcione, debe recibir una recompensa distinta de cero después de cada paso
  4. RL funciona maximizando la recompensa para cada siguiente paso inmediato

Respuesta Correcta: (b)

Justificación detallada:

  • (a) FALSO: RL no minimiza pérdida entre predicciones y etiquetas como ML supervisado. No hay "etiquetas correctas" dadas.
  • (b) VERDADERO: Esta es la definición precisa de RL según Sutton & Barto. El agente debe aprender a tomar buenas decisiones con poca supervisión.
  • (c) FALSO: RL funciona con recompensas escasas. Muchos problemas tienen recompensas cero la mayoría del tiempo (ej: ajedrez).
  • (d) FALSO: RL maximiza la recompensa ACUMULADA a largo plazo, no solo el siguiente paso inmediato.

1.2 Q-Learning y Off-Policy

Describe la actualización de Q-Learning. ¿Es off-policy? ¿Por qué?

Actualización Q-Learning:

Q(s,a) ← Q(s,a) + α[r + γ maxa' Q(s',a') - Q(s,a)]

¿Es off-policy? SÍ

Porque: Usa una política de exploración (ε-greedy) para generar datos, pero aprende la política greedy usando el max.

Las acciones tomadas no tienen que ser óptimas para aprender la política óptima.

1.3 Control vs Predicción

Explica la diferencia entre problemas de control y predicción en RL.

Dimensión Predicción Control
Objetivo Estimar Vπ(s) bajo política fija Encontrar política óptima π*
Política Dada y fija Mejora iterativamente
Actualización V(s) ← V(s) + α[r + γ V(s') - V(s)] Q(s,a) ← Q(s,a) + α[r + γ maxa' Q(s',a') - Q(s,a)]

La diferencia clave: En predicción usas V(s') (valor bajo política actual). En control usas maxa' Q(s',a') (mejor valor posible).

1.4 ¿Qué es un MDP?

¿Qué es un MDP? ¿Qué relación tiene con RL?

Definición Formal:

M = (S, A, P, R, γ)

  • S: Estados
  • A: Acciones
  • P(s'|s,a): Probabilidades de transición
  • R(s,a,s'): Función de recompensa
  • γ: Factor de descuento

Relación con RL:

  • MDPs formalizan los problemas de RL
  • Todas las ecuaciones de Bellman asumen un MDP
  • Resolver un MDP = resolver el problema de RL
